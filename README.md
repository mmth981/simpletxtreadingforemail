## About

simpletxtreadingforemail is a lightweight tool for cleaning up messy email text and removing clutter so the important content is easier to read.

It strips out HTML noise, quoted replies, disclaimers, and repeated thread content, then gives you a cleaner plain-text version you can copy or download.

## Features

- Paste raw email text or HTML
- Remove quoted replies and boilerplate
- Keep the useful message content
- Copy or download the cleaned output as a .txt file
